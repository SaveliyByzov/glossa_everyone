# Итальянский (`it`) — логика подачи

Курс: **режим `review`**, уровень **A1→B2** сжато. Пользователь — русскоязычный, филологически подготовленный, раньше учил итальянский. Поэтому:
- теория короткая, но точная; лексика частотная, без «детских» тем;
- упор на зоны, где интерференция с русским устойчива: артикль, вспомогательный глагол, imperfetto / passato prossimo, клитики, congiuntivo, согласование времён;
- где полезно — исторические и латинские комментарии (`tip`): филологу проще запомнить *le uova* или *fece*, зная их происхождение.

Файлы: `data/it/index.js`, `data/it/u01.js` … `u08.js`. Упражнения (`uNN.ex.js`) — за методологом.

## 3. Трудности для русскоязычных

1. **Артикль.** В L1 категории нет → систематический пропуск (*Amo musica*) и неверный выбор формы (il/lo по первому звуку следующего слова, а не существительного). Отдельно: артикль при притяжательных (*il mio libro*, но *mia madre*), при странах (*l’Italia*) и его отсутствие при городах.
2. **Вспомогательный глагол.** В русском нет аналога → *ho andato*. Даём рабочий тест (переходность + движение/изменение состояния) и, для филолога, термины неаккузатив/неэргатив. Глаголы с двумя вспомогательными (finire, salire, correre, cambiare) — отдельно.
3. **Imperfetto / passato prossimo vs вид.** Параллель «imperfetto ≈ несов., passato prossimo ≈ сов.» полезна как старт, но с оговорками, которые в теории даны явно:
   - ограниченная длительность → passato prossimo при русском несов. (*Ho vissuto a Roma dieci anni* — жил);
   - общефактическое значение несов. вида («ты читал эту книгу?») → passato prossimo;
   - подсчитанное повторение (*tre volte*) → passato prossimo;
   - в итальянском это противопоставление времён только в прошлом, а русский вид — во всех временах;
   - лексические сдвиги: conoscevo / ho conosciuto (знал / познакомился), sapevo / ho saputo, dovevo / sono dovuto.
4. **Клитики.** Позиция (проклиза / энклиза), обязательность (*Sì, lo conosco*, *Ne ho due* — в русском дополнение опускается), сочетания (*glielo*), согласование причастия с lo/la/li/le/ne, расхождения управления (*aiutare qn* — вин. vs «помогать кому»; *chiedere a qn* — дат. vs «спросить кого»).
5. **Congiuntivo.** Воля совпадает с русским «чтобы» (опора), а мнение (*penso che sia*) — нет: русский даёт индикатив. Перенос времени в прошлом (согласование времён) — в русском отсутствует. Будущее в прошедшем через condizionale passato (*ha detto che sarebbe venuto*) — устойчивая ошибка.
6. **Periodo ipotetico.** Русское «бы» в обеих частях → калька *se avrei*. Правило: после условного *se* condizionale невозможен.
7. **Ложные друзья** (отмечены в `note` лексем): *bravo* (умелый, не «храбрый»), *libreria* (книжный магазин), *giornale* (газета), *campagna* (сельская местность), *camera* (комната), *finalmente* (наконец), *pretendere* (требовать), *occasione* (возможность), *magari*.
8. **Удвоенные согласные** и ударение в 3 л. мн. ч. (*pàrlano*, *àbitano*, но *parlàrono*), различие *-emmo / -emo* (condizionale / futuro).

## 4. Конвенции данных

- id лексем: `it-<слово без диакритики>`, при омонимии — суффикс (`it-potere` глагол / `it-potere-n` «власть»).
- Существительные: `forms: 'il libro, -i'`; неправильные — полностью (`'l’uomo, gli uomini'`, `'l’uovo, le uova (ж.)'`); неизменяемые — с артиклем мн. ч. (`'la città, le città'`). `g`: m / f / c (общий род: *collega*, *ospite*).
- Глаголы: `forms: '<1 л. ед. презенса>[, другие неправильные]; <причастие> (<вспомогательный>)'`, напр. `'vado; andato (essere)'`, `'salgo, sali; salito (essere / avere)'`. Для глаголов с нестандартным ударением оно показано знаком в форме (`àbito`, `dimèntico`) — это только справочная разметка, не орфография.
- Прилагательные: `'nuovo, -a, -i, -e'` / `'grande, -i'`.
- Нетривиальное ударение существительных — в `note` («ударение: màcchina»).
- Апостроф в итальянских словах — типографский `’` (U+2019), как в нормативной печати.

## 5. Норма письма и политика проверки ответов

**Ударения.** В итальянском знак ударения обязателен только на конечной ударной гласной (*città, perché, più, è*) и на нескольких односложных омографах (*dà* ≠ *da*, *è* ≠ *e*, *là* ≠ *la*, *sì* ≠ *si*, *tè* ≠ *te*, *né* ≠ *ne*, *sé* ≠ *se*). Пропуск такого знака — **ошибка** (часто смыслоразличительная: *e* «и» vs *è* «есть»). Поэтому `optionalMarks` пуст.

**Грав / акут.** Нормативно: *à ì ò ù* — всегда грав; на *e* — грав для открытого /ɛ/ (*è, caffè, tè*), акут для закрытого /e/ (*perché, né, sé, poiché, -tré*). Решение: **è и é глобально не взаимозаменяемы** (`equivalents: []`). Обоснование: (1) чисто нормативная разница, но именно её стоит закреплять у продвинутого ученика; (2) пар, различающихся только è/é на конце, практически нет, поэтому перепутанный знак не ломает смысл — это «почти верно», а не «неверно». На практике *perchè* (6 букв) уже ловится общим правилом движка «почти верно, 1 символ при длине ≥ 5». Для коротких слов, где это важно, методолог при необходимости добавляет вариант в `answers`. Буквы *ó, í, ú* на клавиатуру не выносим (в стандартной орфографии не используются).

**Апостроф вместо ударения.** Пользователь без раскладки может набрать *e'*, *perche'*, *piu'* (так пишут на латинской клавиатуре). Предлагаю это принимать: новое поле политики

```js
answer.apostropheAccent = { "a'": 'à', "e'": 'è', "i'": 'ì', "o'": 'ò', "u'": 'ù' }
```

Правило для движка: в **вводе и эталоне** одинаково заменить «гласная + `'`/`’` на конце слова» на соответствующую гласную с гравом, затем сравнивать как обычно. Следствия:
- *e'* = *è* ✔; *piu'* = *più* ✔; *perche'* → *perchè* — расходится с *perché* в одном знаке → «почти верно» (согласуется с политикой è/é);
- законные апострофы на конце слова (*po’* < poco, императивы *va’, fa’, da’, sta’, di’*) нормализуются **на обеих сторонах одинаково**, поэтому верный ответ остаётся верным. Цена — мелкая снисходительность (*dà* и *da’* перестают различаться при проверке; *di’* = *dì*) — приемлема;
- апострофы элизии (*l’amico, un’amica, dell’, quell’*) стоят после согласной/перед словом и правилом не затрагиваются.

Это **расширение контракта** (поля `apostropheAccent` нет в CONTRACT.md). Если движок его не знает, поле игнорируется и курс работает как раньше (апостроф тогда просто не засчитывается за ударение). Также движку стоит отождествлять апострофы `'` (U+0027) и `’` (U+2019) — в данных используется типографский.

**Прочее:** регистр игнорируется (`ignoreCase: true`); прописная *Lei/La/Le* (вежливая форма) при проверке не важна. Разговорные, но ненормативные варианты (индикатив после *penso che*, *se lo sapevo, venivo*) в теории описаны, но в ответах не принимаются.
