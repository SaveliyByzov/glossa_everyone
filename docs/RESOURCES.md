## Особенности нормы (подтверждено перечисленными страницами)

- **Экавица / иекавица.** Сербия — преимущественно экавица (*mleko, lepo*); босняцкий, хорватский, черногорский
  стандарты и иекавская версия сербского — иекавица (*mlijeko, lijepo*). Новосадское соглашение 1954 г. уравняло оба
  произношения. Курс использует экавицу (восточный стандарт) и отмечает иекавские варианты в заметках.
- **Ударение.** Четыре акцента (два тона × долгота); в письме не обозначаются, в словарях помечаются. Для
  большинства говорящих различие краткого восходящего и нисходящего стёрто — для A0–B1 достаточно знать место
  ударения и «не акать» (*voda* — [вода]).
- **Сербский / хорватский / боснийский.** Единая штокавская основа (грамматика почти общая); различия — в лексике
  (*hleb* / *kruh*, *voz* / *vlak*), будущем времени (*radiću* / *radit ću*), da + презенс вместо инфинитива (сербская
  предпочтительность), орфографии. В Сербии кириллица конституционно приоритетна, латиница в быту равноправна; в
  Боснии обе графики равны.

## Идеи для приложения

1. **Ударение.** Хранить в данных слова с ударением (напр. `voda` → `vòda`) и показывать по нажатию на слово; отдельный
   тренажёр «где ударение»; источник — словарные данные (srLex / Викиречник) с проверкой лицензии.
2. **Аудио.** Сейчас только `speechSynthesis` (если в системе есть сербский голос). Варианты: короткие собственные записи
   (CC0/CC BY) для ключевых слов и диалогов, кэшируемые Service Worker’ом; Common Voice — только если условия
   позволят.
3. **Диалоги.** Адаптированные диалоги A1–A2 в ситуациях (магазин, кафе, транспорт) с режимом «скрыть перевод» и
   упражнением на порядок реплик; готовое чтение в курсе есть (`lesson.text`), добавить отдельный тип «диалог».
4. **Энклитики.** Тренажёр второго места (*Juče mi ga je dala*) — самое трудное; отдельный навык и тип упражнения
   «расставь кластер».
5. **Примеры из корпуса.** Для частых слов подбирать реальные предложения из Tatoeba / srWaC (с учётом лицензии CC BY-SA)
   в виде офлайн-набора.
6. **Иекавские варианты.** Переключатель «показывать иекавицу» для лексики (*mleko → mlijeko*) и переключатель
   «хорватские/боснийские соответствия» в заметках к словам.
7. **Ложные друзья и интерференция.** Режим повторения «ловушки» с карточками из справочника.
