# Srpski (Glossa · Srpski)

Офлайн-приложение для изучения сербского: грамматика и лексика с нуля (A0–B1) для русскоговорящих.
PWA на чистых HTML + CSS + ES-модулях, без сборки и зависимостей; работает в браузере, ставится на телефон
«как приложение» и собирается в APK / iOS через Capacitor. Это отдельная сербская версия проекта Glossa.

* **Курс сербского** (10 юнитов, 44 урока, ≈490 слов): алфавиты, biti, презенс, 7 падежей, перфект, вид, футур, da-конструкции.
* **Алфавит показа**: переключатель «латиница / кириллица» в шапке (по умолчанию латиница) — вся теория, лексика, примеры
  и задания транслитерируются на лету (`js/script.js`); ответ принимается в любом алфавите. Клавиши спецсимволов
  следуют выбранному алфавиту: латиница — č ć š ž đ, кириллица — ђ ј љ њ ћ џ.
* **Справочник**: алфавит с произношением, шпаргалки по падежам и спряжению, ложные друзья, ссылки на внешние ресурсы
  (docs/RESOURCES.md — проверенный список).
* Оформление: одно, «Игровое»; цвет: авто / светлая / тёмная; акцент — приглушённый синий триколора.

Документы: [CONTRACT.md](CONTRACT.md) (архитектура и схема данных), [docs/PEDAGOGY.md](docs/PEDAGOGY.md) (методика),
[docs/DESIGN.md](docs/DESIGN.md) (дизайн-система), [docs/linguistics/sr.md](docs/linguistics/sr.md) (курс),
[docs/RESOURCES.md](docs/RESOURCES.md) (ресурсы для изучения).

## Запуск локально

Нужен статический сервер (ES-модули и Service Worker не работают с `file://`).

```bash
npm run serve            # = node tools/serve.mjs 8080  → http://localhost:8080/
```

После правок файлов пересоберите Service Worker: `npm run build:sw` (список precache и версия кэша = хэш содержимого).

## Проверки

```bash
npm test                 # node:test: ответы, транслитерация, SRS, разметка, мастерство/XP, валидатор
npm run validate         # валидатор курса: node tools/validate.mjs [sr] [--strict]
npm run icons            # перерисовать иконки (Ћ на синем): python tools/make-icons.py
```

Тестовые фикстуры (мини-курс со всеми типами упражнений) — `tests/fixtures/demo/`.

## Установка на телефон (PWA)

PWA ставится с https-адреса (или localhost). iPhone/iPad (Safari): «Поделиться» → «На экран „Домой“». Android (Chrome):
меню ⋮ → «Установить приложение». После первого открытия всё кэшируется и работает без интернета. Прогресс хранится в
`localStorage` (ключ `glossa:v1`), экспорт/импорт JSON — в «Профиле». Там же «код переноса» (копировать/вставить) и, если владелец подключил сервер, анонимная синхронизация между устройствами по фразе-ключу (E2E-шифрование, без e-mail и паролей) — см. `docs/SYNC.md`.

## Capacitor

`npm run cap:android` / `npm run cap:ios` (appId `app.glossa.srpski`).
